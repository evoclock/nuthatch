Nuthatch — pipeline architecture (Mermaid)

Two diagrams rendered live by Mermaid v10. The D2 version of the same content is at nuthatch_pipeline_d2.html.

How to read this page. The data lifecycle traces a source file through the five pipeline stages and the artifacts each stage emits. The module graph shows the Python packages under src/nuthatch/ and their import dependencies. Edges are colored by source: in the lifecycle, by the stage that emitted the edge; in the module graph, by the module that imports from elsewhere. Palette: thermall power-station.
